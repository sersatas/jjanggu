# 짱구 어시스턴트

거실 태블릿용 음성 비서. "짱구야, 날씨 어때?" / "짱구야, 아이유 노래 틀어줘"

서버 없이 태블릿 브라우저 혼자 동작한다. `docs/` 폴더가 앱 전체이고 GitHub Pages(https)로 올린다.

- 듣기: 크롬 음성인식 (호출어 "짱구야")
- 이해: Gemini 함수호출 (`brain.js`). 기본 `gemini-3.5-flash-lite`, 바쁘거나 한도에 걸리면 `gemini-3.6-flash` → `gemini-3.5-flash` 로 자동 전환
- 날씨·미세먼지: Open-Meteo (무료, 키 없음)
- 노래: YouTube Data API 검색 → 화면 플레이어로 재생
- 말하기: 태블릿 내장 TTS

## 태블릿에서 처음 한 번

1. 크롬으로 `https://sersatas.github.io/jjanggu/` 접속
2. 화면 터치 → 설정 화면에 Gemini 키, YouTube 키 입력 → 저장
3. 마이크 **허용**
4. 크롬 메뉴 ⋮ → **홈 화면에 추가** 하면 앱처럼 전체화면으로 열린다

키는 그 태블릿 브라우저(localStorage)에만 저장되고 GitHub에는 올라가지 않는다.
나중에 키를 바꾸려면 오른쪽 위 ⚙ 를 누른다.

## API 키 보호 (꼭 하기)

키가 브라우저에 있으므로, 구글 클라우드 콘솔에서 두 키 모두 사용처를 이 사이트로 제한한다.

1. https://console.cloud.google.com/apis/credentials → 키 선택
2. **애플리케이션 제한사항** → **웹사이트** → `https://sersatas.github.io/*` 추가
3. 저장 (적용까지 몇 분 걸릴 수 있음)

이렇게 하면 키가 유출돼도 다른 사이트에서는 쓸 수 없다.
제한 후에는 PC의 `localhost` 테스트도 막히므로, PC에서 시험하려면 `http://localhost:8888/*` 도 같이 추가한다.

## 이렇게 말하면 돼요

- "짱구야" (띵 소리) → "내일 우산 챙겨야 돼?"
- "짱구야 부산 미세먼지 어때"
- "짱구야 비 오는 날 듣기 좋은 노래 틀어줘"
- "짱구야 다음 곡" / "소리 줄여" / "멈춰" / "꺼 줘"
- "짱구야 지금 나오는 노래 뭐야"

## PC에서 고쳐서 시험하기

`start.bat` 실행 → `http://localhost:8888` (키는 그 브라우저의 설정 화면에서 따로 입력)
고친 뒤 GitHub에 push 하면 1~2분 뒤 태블릿에도 반영된다.

무료 Gemini 키는 모델당 분당 15회 정도 제한이 있다. 날씨·노래 질문은 한 번에 2회씩 쓴다.
